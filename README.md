An autonomous algorithmic trading, technical indicator calculation, market sentiment scraper, and Monte Carlo portfolio risk simulation platform.

---

## ⚡ Core Engine Features

- **Technical Analysis Pipeline**: Real-time calculation of RSI (14), MACD (12, 26, 9), EMA/SMA crossovers, and Bollinger Bands.
- **Gemini Market Sentiment Engine**: Scrapes real-time financial headlines and assesses macro sentiment score.
- **Backtesting & Monte Carlo Simulator**: Historical trade execution simulation with maximum drawdown, Sharpe ratio, and Value-at-Risk (VaR).
- **Position Sizing & Stop-Loss Auto-Calculators**: Enforces strict Kelly Criterion and risk-per-trade rules.

## 🚀 Getting Started
