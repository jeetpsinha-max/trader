## Summary
AI TradeBot & Financial Market Intelligence Platform — automated sentiment analysis, technical indicator calculations, live financial news scraping, and AI trading recommendations.

## Core Features
*   **Full-Stack Express API Server:** Node.js/Express backend (`server.ts`) for web scraping and Gemini trade analysis.
*   **`ai_tradebot.py`:** Automated trade signals and logic.
*   **Web scraping engine (`cheerio`):** Live financial news scraping.
*   **Real-time charts:** Real-time stock/crypto charting.
*   **Gemini market sentiment analysis:** AI-driven sentiment analysis.
*   **Firebase database sync:** Real-time data synchronization.

## Setup Guide
1. **Node.js Environment:**
   ```bash
   npm install
   npm run dev
   ```
2. **Python Environment:** Set up a virtual environment and install requirements for the backend.
3. Configure API keys (Gemini, Firebase, etc.) in the environment.
4. Run the dev server and the Python bot simultaneously.
